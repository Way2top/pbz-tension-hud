# 影之刃零 · Tension HUD 正式版 v1.0.0

战斗时在屏幕右上角显示一个半透明面板，实时呈现游戏内置的 **Tension（受压评分）**——
隐藏在 `TensionMeter` 插件里、范围 −100 ~ +100、分六个档位的那套数值。

> **只读**：本 mod 只读取游戏数据，不修改存档、不影响进度、不改变游戏平衡。

---

## 前置要求

| 项目 | 要求 |
|---|---|
| 游戏 | 《影之刃零》Steam 版，且版本与本 mod 适配的一致 |
| 加载器 | **UE4SS 3.0.1**（游戏目录下存在 `platform\steam\dwmapi.dll`）|
| 运行库 | .NET Framework 4.x（Win10 / Win11 自带）|

> 双击压缩包内的 `检查环境.bat` 可自动检查前两项。

## 安装

1. 关闭游戏
2. 把压缩包拖进 `模组管理器UEModManager`；或解压到游戏根目录，解压后应存在：
   `<游戏根目录>\platform\steam\ue4ss\Mods\PBZTensionHUD\Scripts\main.lua`
3. 启动游戏。mod 会自动拉起覆盖层，**面板默认隐藏**
4. 进入 BOSS 战后按 `F7` 呼出

## 卸载

关闭游戏，删除 `platform\steam\ue4ss\Mods\PBZTensionHUD\` **整个目录**。

临时关闭：把该目录里的 `enabled.txt` 改名为 `enabled.txt.disabled`，重启游戏；恢复时改回来。

> ⚠️ 只改**文件夹名**无效——UE4SS 会扫描 `Mods/` 下任何含 `enabled.txt` 的子目录，改名后 mod 仍会加载，还会因为找不到 exe 进入「Lua 在跑、没有面板」的中间状态。

## 键位

| 键 | 功能 |
|---|---|
| `F7` | 显示 / 隐藏面板（默认隐藏）|
| `F8` | 切换预设：完整版（含 20 条基础权重表）↔ 标准版 |
| `F9` | 权重表翻页（共 4 页）|
| `F10` | 重启覆盖层（面板消失时使用）|

## 面板内容

从上到下：

1. **标题** — 影之刃零 · TENSION
2. **BOSS 名 + 双方血条**
3. **档位印章** — 竖排两个字描述当前气势，旁配四字短评
4. **分值** — 当前 Tension 数值（−100 ~ +100，一位小数）
5. **实时曲线** — 最近 30 秒走势
6. **趋势 / 峰值** — 每秒变化量与 10 秒内峰值
7. **四维** — 防御 / 闪避 / 进攻 / 节奏
8. **战况** — 每个动作一行：分值 / 事件名 / 基础权重，同屏 6 行

### 档位对照

| 档位 | 主词 | 短评 |
|---|---|---|
| 0 | 从容 | 游刃有余 |
| 1 | 沉稳 | 章法有度 |
| 2 | 相持 | 势均力敌 |
| 3 | 吃紧 | 渐落下风 |
| 4 | 失措 | 阵脚已乱 |
| 5 | 难支 | 命悬一线 |

> 分值越低（越负）你越占上风；越高（越正）你越被动。

### 评分是怎么来的

```
动作事件 → 查基础权重（20 种）→ 乘 17 个乘数 → 归入 6 个维度之一
        → 维度累计 → 加权求和 + 模式加成 → 最终分值（−100 ~ +100）
```

- 面板显示的是「四维」的累计值，是最终分的**来源之一**
- 游戏实际有 6 个维度（另有血量、架势），面板只显示其中 4 个
- 因此四维数值相加 ≠ 总分

**重要澄清**：这套评分**不直接驱动 BOSS AI**。
A/B 实测中，评分与 BOSS 出招频率的相关性只有 r = 0.24。
真正影响战斗走势的是：杀气槽与硬直、AI 脚本（受击计数 / 概率门限）、难度设置。

## 常见问题

**面板不出现**
先按 `F10` 重启覆盖层；仍无效则查看 `%TEMP%\PBZTensionHUD\overlay.log`。

**一直显示「未检测到 BOSS」**
只有 BOSS 战期间才有会话数据，普通探索时属正常。

**全屏看不到**
请使用「无边框全屏」或「窗口模式」；独占全屏下覆盖层会被游戏遮挡。

**杀毒软件误报**
覆盖层程序未签名，可能被误判，加入白名单即可。

**会影响存档吗？**
不会。mod 不调用任何存档接口。

**和「首领再战」mod 一起用有问题吗？**
可以共存，两个 mod 互不依赖。但注意：**首领再战 mod 自身在「连战途中强退游戏」时，可能把竞技场状态写进存档**——
这不是本 mod 的问题，但如果你两个都装，建议不要在对战中途强杀游戏进程。

**游戏更新后失效**
游戏内部结构变更可能导致读不到数据，需要等待适配版本。

**同时开了两个覆盖层**
有单实例锁，第二个会自动退出，属正常。

## 已知限制

1. 权重表显示的是**基础权重**，不含乘数结算后的最终值
2. 架势 / 血量维度的实时值游戏未暴露，故不显示
3. 覆盖层是独立进程，不在游戏渲染管线内；游戏退出后约 10–15 秒自动关闭
4. 仅支持无边框全屏 / 窗口模式
5. 游戏大版本更新后可能需要适配
